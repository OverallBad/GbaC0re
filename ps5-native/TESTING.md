# GbaC0re PS5 Native v2.0.0 — Testing

## What was verified on the build host (2026-09-29)

- `prospero-clang` (LLVM 18.1.8, target `x86_64-sie-ps5`) compiled every
  application and mGBA object with `-O2 -Wall`: **zero warnings in our
  code** (one intentional `#warning` inside mGBA's own `formatting.c`
  about `localtime_r`, expected on this platform).
- `link_real` linked `app.elf` (1,092,016 bytes) with **zero unresolved
  imports**. ELF type `ET_SCE_DYNEXEC`, imports exactly:
  `libc.prx`, `libkernel.prx`, `libSceSystemService.prx`,
  `libSceVideoOut.prx`, `libSceAudioOut.prx`, `libSceUserService.prx`,
  `libScePad.prx`.
- `make_fself.py --ptype fake` produced a valid SELF `eboot.bin`
  (1,041,190 bytes, magic `4F 15 3D 1D`).
- All 29 link-protocol loopback tests pass (`link/test_link.c` vs the
  current `link_proto.c`): handshake, retransmit, dup/lost packet
  recovery, deferred responses, re-handshake.

## NOT verified — needs Ty's hardware test on 13.60

Nothing below has run on a PS5. The title may fail at any of these
points; `gbac0re.log` in the title folder records boot breadcrumbs.

### Boot chain (in order)
1. ps5link CRT startup (`crt1_ps5.o`) on 13.60 — tested by ps5link only
   on 9.00.
2. `sceSystemService` splash + main entry.
3. `gbac0re.log` append — confirms the working directory is writable.
4. Filesystem ROM scan (`open`/`getdents`/`close` on `roms/`).
5. ROM load through the mGBA core.
6. First emulated frame (VideoOut init, 1920×1080 tiled buffers).
7. Audio init (AudioOut, 48 kHz, 256-frame grains).

### Hardware-unverified imports / behavior
- **Direct VideoOut**: 32 MB direct memory split into two 16 MB
  regions, linear scratch composition, tiled blit. Flip sync polls
  `sceVideoOutIsFlipPending` (cataloged; signature and runtime behavior
  unverified) with a bounded spin and no yield.
- **Direct AudioOut**: blocking 256-frame grain output as the master
  frame clock.
- **ScePad**: standard polling; `PAD_CREATE` corrected to `0x00000004`.
- **Filesystem**: relative paths (`roms/`, `saves/`, `states/`,
  `gbac0re.log`) — whether they resolve to the installed title folder on
  13.60 is unconfirmed.
- **Networking**: the link-cable backend uses cataloged `socket`,
  `bind`, `connect`, `send`, `recv`, `fcntl`, plus a computed-NID
  `recvfrom` import added for this title (`vendor/ps5link-sdk/linker/
  catalog_extra.c`). `recvfrom`'s NID is generated by `nid_encode()`
  from the symbol name with the confirmed libc.prx salt — it resolved
  at link time but is **not hardware-confirmed** (same caveat as
  ps5link's other computed entries; `opendir` is the known example of a
  computed entry that crashes at runtime). `sendto`/`select`/`inet_pton`
  were deliberately avoided: the backend uses `connect()`+`send()`,
  1 ms `MSG_PEEK` polling via `sceKernelUsleep`, and a manual IPv4
  parser. Link mode is PS5↔PS5 (or PS5↔PC v1.1, same protocol v1).
- **Notifications**: `sceKernelSendNotificationRequest` with a 3120-byte
  request, message text at offset 45.
- **ShadowMountPlus** registration and the user-supplied `libc.prx`.

### Suggested test order
1. Title appears after ShadowMountPlus registration.
2. Boot → ROM picker lists `.gba` files (check `gbac0re.log`).
3. Load a ROM → video + audio + input.
4. Pause menu: save state, load state, change ROM, options, quit.
5. Fast-forward R1 cycle (OFF → 2× → 4× → OFF).
6. Link-cable HOST/JOIN between two consoles.

### Known limitations
- Single-player only per console; link-cable is 2-player, same ROM both
  sides.
- No Lua, no payload swapping, no JIT — intentionally removed for the
  native port.
- Frame pacing assumes audio blocking is the master clock; if AudioOut
  behaves unexpectedly, video may tear or stall.
